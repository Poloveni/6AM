Bot non relié

Le site n'est pas encore branché sur le bot Discord. Sur le VPS, lance une seule fois (installe le bot puis le relie au site) :

sudo bash /opt/sixam/server/deploy/bot-install.sh

Le site obtient alors un accès en lecture seule : il affiche les données du bot mais ne peut jamais les modifier.
