Installation du bot

Ajouter et configurer le bot sur le Discord 6AM

Chargement…

Le bot est hébergé sur le VPS et relié au site. Il reste à l'ajouter au serveur Discord 6AM puis à le configurer, dans cet ordre. Toutes les commandes /config demandent la permission Administrateur sur le serveur 6AM. Clique sur une commande pour la copier.

  1. Inviter le bot sur le serveur 6AM

    Ouvre le lien, choisis 6AM, puis Continuer et Autoriser (permission « Gérer le serveur » nécessaire).

    Inviter le bot

    Si les salons de logs du jeu (coffres, garages) sont privés, donne l'accès au rôle Roxwood Network Darkbot : « Voir le salon » et « Voir les anciens messages ».

    Contrôle : le bot apparaît dans la liste des membres avec l'étiquette APP.

  2. Choisir le type d'organisation

    /config type-groupe set → Gang ou Organisation. Il fixe les limites de braquage, les labos et les taxes. /config type-groupe list affiche le barème.

  3. Créer les salons du bot

    Crée une catégorie Bot 6AM (clic droit sur le nom du serveur → Créer une catégorie ; si elle est privée, ajoute le rôle Roxwood Network Darkbot). Puis /config category set et choisis Bot 6AM.

    Contrôle : « X salon(s) créé(s) » — stock, quotas, paie, armurerie, taxes, bilan, admin, labos…

  4. Brancher les salons de logs du jeu

    • /config channel add-log-coffre → chaque salon de logs de coffre de 6AM ;
    • /config channel set → rôle logs_garages → le salon des logs de garage (fourrières) ;
    • /config channel set → rôle coffre_admin → le salon du coffre admin, s'il existe.

    Contrôle : /config channel list

  5. Donner les droits

    /config role set → cible admin → rôle de la direction (commandes sensibles), puis cible taxes → rôle qui gère les taxes.

  6. Déclarer les objets du coffre

    /config item add pour chaque objet. Le nom doit être écrit exactement comme dans les logs du jeu (accents, majuscules) : sinon l'objet est ignoré sans message. Options : vente_pnj (drogue vendue aux PNJ), groupe (regroupement), labo_lie (labo qui le produit). Déjà créés : Munition de pistolet, Argent Sale, Argent.

    Contrôle : /config item list

  7. Fixer les objectifs et la paie

    /config quota set (objectif de la semaine) et /config salaire set ($ par unité), pour actions, vente, recolte, labos. Sans objectif, une catégorie n'apparaît pas ; sans taux, elle ne rapporte rien.

  8. Relier les noms en jeu aux comptes Discord

    /adduser pour chaque membre (nom en jeu ↔ compte Discord), sinon ses mouvements de coffre ne lui sont pas attribués. Contrôle : /listusers

  9. Importer l'historique du coffre

    /sync-stock relit les anciens logs et calcule le stock actuel.

    Contrôle final : les panneaux apparaissent dans stock, quotas, armurerie et taxes, et la page Le Bot se remplit (mise à jour chaque minute).

Si ça coince

/config n'apparaît pasAttendre 1 minute puis Ctrl + R dans Discord ; vérifier qu'on est sur le serveur 6AM et Administrateur.
Le coffre ne bouge pasOrthographe de l'objet différente des logs, ou le bot ne voit pas le salon de logs (étape 1).
« Cannot rename channel »Donner au bot « Gérer les salons » sur les salons de labo.
Un panneau n'apparaît pas/config channel list et vérifier que le bot peut écrire dans le salon.
Le Bot : « La base du bot ne répond pas »Sur le VPS : sudo bash /opt/sixam/server/deploy/bot-install.sh (Entrée aux deux questions).

Mise à jour du bot : relancer la même commande sur le VPS. Documentation complète : README du bot.
